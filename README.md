# Django Email OTP System

A secure, production ready **Email OTP Authentication system built with Django** usingcustom user model, OTP hashing and session-based authentication.

## Features
- Enail-based authentication (OTP login)
- Secure OTP (never stored in plaintext)
- OTP expiration (5 minutes)
- Attempts limits (brute-force protection)
- Auto user registration on first login
- Session-based authentication (no JWT overhead)
- Email OTP delivery via SMTP or console backend

## Tech Stack
- Django
- SQLite(default DB)
- Django Auth System
- SMTP / Console Email Backend
